Privacy Policy

Bianca AI Uploader · Last updated: 2026-10-29

1. YouTube API Services

Bianca AI Uploader uses YouTube API Services. By using this tool, you agree to be bound by the YouTube Terms of Service. Your data is also handled under the Google Privacy Policy.

2. Who uses this tool

The tool is used only by the owner of the YouTube channel @Bianca_AIart_music, on the owner's own PC. It is not offered to other people.

3. What information is accessed

  • The Google account the owner signs in with, through Google OAuth 2.0.
  • The owner's own channel name and channel ID (to confirm sign-in).
  • The video files, titles, descriptions, tags and thumbnails that the owner chooses to upload.

The tool does not access any other user's personal information, comments, subscriptions or analytics.

4. How information is used

The information is used only to upload the owner's videos and their metadata to the owner's own channel.

5. Storage

  • The OAuth access/refresh token is stored only in a local file on the owner's PC. It is never sent anywhere except Google's servers.
  • A local log file keeps the upload date, file name, video ID and title of the owner's own uploads.
  • No data is stored on any server operated by this tool. There is no server.

6. Sharing

No information is shared with, sold to, or disclosed to any third party. Data is sent only to Google / YouTube through the YouTube API Services in order to perform the upload.

7. Cookies and tracking

The tool and this website do not use cookies, analytics or any tracking technology.

8. Revoking access and deleting data

  • Access can be revoked at any time from the Google security settings page.
  • Deleting the local token file and log file removes all stored data from the PC. Stored API data is deleted or refreshed within 30 days, as required by the YouTube API Services Developer Policies.

9. Contact

Questions about this policy: please open an issue at github.com/biancaAI/bianca-ai-uploader/issues.
