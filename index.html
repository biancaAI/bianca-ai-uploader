Bianca AI Uploader

A personal upload tool for the YouTube channel @Bianca_AIart_music

What it is

Bianca AI Uploader is a small command-line tool that runs only on the channel owner's own Windows PC. It uses YouTube API Services (YouTube Data API v3) to upload the owner's original AI-generated animation videos to the owner's own YouTube channel, together with the title, description, tags, thumbnail and the "altered or synthetic content" disclosure.

It is not distributed, sold or offered to anyone else. The only user is the channel owner.

What it does

  • Signs in with Google OAuth 2.0 (the owner's own account only).
  • Uploads a video file from the owner's PC (videos.insert).
  • Sets the custom thumbnail (thumbnails.set) and optionally adds the video to the owner's playlist (playlistItems.insert).
  • Reads the owner's channel name to confirm sign-in (channels.list).

It does not read, collect or analyse any other user's data, comments or statistics.
